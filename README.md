## What it does

`main.py` (Python standard library only) writes exactly one sentence — a
childhood memory — to `/output/entry.txt`:

> Every August evening my grandmother stood at the stove in her faded apron, frying rice while the cicadas sang outside, and I sat on the counter swinging my legs, not knowing those were the last summers I would ever taste.

The sentence is 221 characters: one concrete summer-evening scene in a
grandmother's kitchen, with a small honest detail (swinging my legs on the
counter) and a warm ache that lingers after it ends.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no arguments. The program creates `/output` if
needed and writes the sentence with no trailing newline.
